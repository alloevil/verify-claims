## How to read this

- **machine** means a command in that repository recomputes the number from committed data, and CI fails when it stops reproducing.
- **manual** means the number is published but not recomputable (an upstream quote, a screenshot, a model-side statistic). Those are the honest gaps: the claims file names, per row, what artifact would be needed to check it.
- This counts the claims that exist today. `docs/measurement.md` counts what an audit examined at the time (553 claims, 131 defective) — different denominators, both labelled.
- A repository with a high manual count is not necessarily worse than one with none — it may simply publish more numbers that depend on the outside world. The count says how much is checkable today, not how careful the authors were.
